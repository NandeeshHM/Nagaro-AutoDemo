# Using REPL (Read–Eval–Print Loop) with Playwright

The **REPL (Read–Eval–Print Loop)** provides an interactive way to work with Playwright by allowing you to execute commands **line by line** and immediately observe their results.

Instead of repeatedly running an entire script, REPL lets you:
- Launch the browser once  
- Experiment with locators and commands in real time  
- Iterate quickly while testing or debugging  

In essence, REPL behaves like a conversation with your code — you issue a command, and the system responds instantly.
